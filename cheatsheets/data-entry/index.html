Памятка автору
  • id = «topicId.суффикс», например math.basics.recap — строчные буквы, цифры, дефисы, точки-разделители.
  • Для текстов XX века (не фольклор, не классика до 1500 г.) — только описание фактов/тем, не цитируйте текст произведения.
  • Таджикский текст — под ревью носителя языка (особенно формы глагола, изафет, фразеология).
  • fixedByUser ставьте вручную, только когда правите карточку по сообщению из кнопки «Сообщить об ошибке» в приложении.
  • Формулы — LaTeX без $…$ в самом поле latex; символ доллара нужен только внутри markdown-текста для inline-формул.
